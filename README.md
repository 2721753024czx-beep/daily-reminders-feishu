# 每日必做 · Apple 提醒事项与飞书

在 iPhone 上用 Siri 新建任务，同时写入苹果提醒事项和飞书多维表格。任一端勾选完成后，iPhone 快捷指令会在下次运行时为另一端补勾。Mac 只用于生成和签名快捷指令，日常运行可以关机。

## 1. 准备飞书多维表格

在飞书创建自己的多维表格和数据表，例如「任务收件箱」。字段名须与下表一致。

| 字段名 | 字段类型 | 用途 |
| --- | --- | --- |
| 任务标题 | 文本，可设为主字段 | 保存任务名称 |
| 截止时间 | 日期，格式包含时分 | 保存苹果提醒时间 |
| 已完成 | 复选框 | 在飞书勾选完成，供 iPhone 同步 |
| 飞书任务 ID | 文本，可选 | 保存飞书任务自动化返回的 ID |

从这张数据表的链接中取出 `/base/` 后的 **Base 标识**和 `table=` 后的 **数据表 ID**。数据表 ID 以 `tbl` 开头。点击多维表格右上角「多维表格插件」→「自定义插件」→「获取授权码」，开启并复制该多维表格的授权码。这个授权码只需在导入指令时填写。它可用于读写你的表，分享快捷指令或截图前请移除授权码。[飞书多维表格授权码 SDK](https://github.com/larksuite/base-sdk-go)

如需在**飞书任务中心**也生成任务，在多维表格里新建一个工作流。触发器选「添加新记录时」，表选「任务收件箱」，条件设为「任务标题」有值，并确保触发范围包括 OpenAPI 新增记录。添加「创建飞书任务」，从触发记录引用「任务标题」和「截止时间」，设定负责人。可再加一步「修改记录」，把创建返回的任务 ID 写回同一条记录的「飞书任务 ID」。保存并启用。[飞书创建任务节点说明](https://www.feishu.cn/hc/zh-CN/articles/447311016689)

## 2. 在 Mac 生成并导入快捷指令

在 GitHub 仓库页点 **Code → Download ZIP**，解压后用终端进入该文件夹。Mac 需要安装 Python 3，并提供系统自带的 `shortcuts` 命令。把下面两个示例值换成自己的标识再执行。

```sh
sh build-shortcuts.sh 'YOUR_BASE_ID' 'tblExample123'
```

在 `dist/` 中找到两个已签名的 `.shortcut` 文件。

1. **新增必做（可同步）**会添加苹果提醒、写入飞书表格，并将飞书记录 ID 存入苹果提醒备注。
2. **同步必做状态**会检查已关联的任务并同步勾选状态。

双击文件添加到 Mac 的「快捷指令」，再通过 AirDrop 或 iCloud Drive 分享到 iPhone。也可以直接把文件传到 iPhone，从「文件」中打开并添加。导入时分别给两条指令填入同一个飞书多维表格授权码。如果没有弹出提示，编辑指令，在顶部「文本」动作里替换授权码占位文字。可在新增指令的「添加新提醒事项」动作里选定自己的提醒清单。[Apple 的 Mac 导入说明](https://support.apple.com/zh-cn/guide/shortcuts-mac/apd02bffbaac/mac)

## 3. 验证，再启用自动同步

1. 在 iPhone 上解锁运行「新增必做（可同步）」，允许访问提醒事项和连接飞书。用不同标题建两条测试任务，确认表里都有记录，苹果提醒备注里都有 `飞书记录：rec…`。
2. 在苹果提醒事项勾选第一条，运行「同步必做状态」，检查飞书表里该条记录的「已完成」。在飞书表里勾选第二条，再运行一次，回到苹果提醒清单并选择「显示已完成」，核对结果。
3. 在 iPhone「快捷指令 → 自动化」里建一个「App」自动化，选择「提醒事项」和「关闭时」，设为「立即运行」并选择「同步必做状态」。切出提醒事项 App 就会触发。
4. 可再建一个每天的「特定时间」自动化，选择同一条指令并设为「立即运行」。这能处理在电脑上勾选后还没有同步的任务。 [Apple 的 App 自动化说明](https://support.apple.com/guide/shortcuts/setting-triggers-apde31e9638b/ios)

日常新建时说「嘿 Siri，新增必做（可同步）」。启用了个人自动化后，照常在任一端勾选。想立刻同步时，也可以说「嘿 Siri，同步必做状态」。

## 常见问题

- **已勾选但另一端没变**。确认 iPhone 当时联网，自动化已启用，苹果提醒的备注里有一条对应本表的 `飞书记录：rec…`。旧任务可在备注里另起一行手动补上记录 ID。
- **苹果有提醒，飞书没有新增记录**。检查飞书授权码和表标识，确认列名、字段类型与上表一致。苹果提醒先创建，重试前先检查两端是否已存在对应记录。
- **表里有记录，飞书任务中心没有**。检查飞书工作流是否启用、是否允许 OpenAPI 触发，并查看工作流运行日志。
- **同步范围**。完成状态以任一端勾选为准。取消完成、改期、周期性提醒和飞书任务中心的完成状态不在同步范围内。
